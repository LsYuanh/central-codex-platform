# 远舟 · Central Codex Platform

**在自己的电脑上与 AI 协作，由中央机统一运行 Codex。**

远舟是一个开源的多用户 AI 工作平台。你可以在桌面客户端中发起对话，让 AI 阅读和修改文件、处理 Git、执行命令，并把生成的文件保存到自己的电脑。管理员通过独立的中央管理 App 配置模型接入、管理用户和设备。

它适合在可信局域网内，由一台中央机为多名用户提供统一的 AI 工作环境。客户端无需安装或运行 Codex，文件和命令操作由目标电脑上的 Local Agent 执行。

## 主要功能

| 功能 | 你可以做什么 |
| --- | --- |
| AI 对话 | 查看流式回复，恢复历史对话，在运行中追加要求或中断任务；管理多个对话，重命名、归档和删除历史 |
| 文件与命令 | 让 AI 读取、修改本机文件，查看 Git 状态和差异，执行命令，并在对话中查看操作结果 |
| 项目管理 | 将本机多个目录组织为项目，按项目管理对话，为任务选择工作目录 |
| 计划与目标 | 先讨论方案，再确认实施；为持续任务设置目标与验收条件，查看进度并暂停或继续 |
| 附件与内容展示 | 添加文件和图片，阅读 Markdown、代码、表格、公式和图表，预览生成的图片与文件 |
| 图片生成与编辑 | 描述要生成的图片，或添加参考图进行编辑；结果通过 Local Agent 保存到本机。需要中央运行包和模型登录支持 |
| 个人技能 | 创建、预览和管理可复用的技能，在输入框用 `$` 搜索并选择，让常用工作方式用于后续对话 |
| 桌面体验 | 中英文界面、明暗主题、托盘驻留、连接与设备状态提示，以及应用内版本更新 |
| 中央管理 | 统一配置模型接入、启停服务、管理用户和设备、发放配对码，并查看运行状态与诊断信息 |

以上能力已有实现，实际可用范围取决于客户端版本、中央运行包和模型能力；各平台的验证情况见[当前状态与限制](#当前状态与限制)。

## 如何工作

远舟由中央端和工作客户端配合运行：

- **中央端**运行 Codex、管理模型登录和对话，安排工具请求。管理员在中央管理 App 中维护服务和用户设备。
- **工作客户端**提供对话界面，内置 Local Agent 在目标电脑上完成文件、Git 和命令操作，并回传结果。配置完成后 Agent 自动启动，无需单独运行。

客户端通过加密连接主动接入中央，无需开放入站 SSH。模型凭据保存在中央；任务所需的文件内容和工具结果会传给中央及上游模型处理。

## 开始使用

使用前需要一台已配置好模型接入和 TLS 的中央机，以及能够连接它的工作电脑。客户端安装包不包含中央服务，也不会自动接入公共服务。

1. **准备中央端。** 管理员按照[中央管理手册](docs/中央管理维护手册.md)配置运行环境、模型登录和服务，再创建用户并发放设备配对码。构建与部署步骤见[开发指南](docs/开发指南.md)和[发布手册](docs/发布与回退手册.md)。
2. **安装客户端。** [客户端 0.3.0 发布页](https://github.com/LsYuanh/central-codex-platform/releases/tag/v0.3.0)提供 Windows x64 安装包和 macOS Apple Silicon DMG。Windows 小包需要电脑已有可用的 WebView2 运行环境。
3. **配对并选择目录。** 打开客户端，填写管理员提供的配对码，选择默认输出目录并保存配置。连接和设备均在线后，即可新建项目或对话。
4. **开始任务。** 输入需求，按需添加附件或选择技能；也可以通过输入框的「＋」选择计划模式或目标模式。

例如，你可以让远舟“解释这个项目的目录结构”“检查当前 Git 修改”，或“先制定修改方案，等我确认后实施”。文件和命令操作使用客户端系统账号的权限；默认输出目录仅决定默认保存位置，不是文件访问的隔离边界。

## 当前状态与限制

项目已有可信局域网内的真实部署，客户端 0.3.0 已发布。当前仍在持续完善，尚未完成完整的生产级隔离和跨平台验收。

- **部署范围：** 当前面向可信局域网，必须校验 TLS 证书；不要将中央网关的 4510 端口直接暴露到互联网。
- **平台验证：** macOS 中央与 Windows Local Agent 的真实模型、文件、命令和历史恢复链路已有验证。macOS 客户端完整交互、部分安装升级场景和 Windows 中央的最新运行包仍有待验收项。
- **图片能力：** 已验证 macOS 中央配合 ChatGPT 登录的图片生成与编辑；Windows 中央、API Key 登录和旧运行包不保证提供该能力。
- **安装与签名：** Windows 安装包尚无 OS 发布者签名；macOS 使用 ad-hoc 签名，尚未公证。更新包的校验签名不等同于系统发布者签名。
- **扩展能力：** 插件和子代理目前未开放。

详细版本、已验证范围和未完成项分别见[项目上下文](docs/项目上下文.md)、[验证与已知限制](docs/验证与已知限制.md)。
