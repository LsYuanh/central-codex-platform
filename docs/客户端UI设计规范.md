## 2026-09-21 新对话项目选择

项目取消和草稿附件移除共用 `composer-remove-button`：22px 圆形按钮、14px SVG 关闭图标，默认透明底和弱文字色，悬停使用 `--hover` 背景与 `--ink` 图标，保留键盘焦点描边。显式覆盖通用主按钮的悬停色，浅深主题均不出现突兀的深色块。

输入框上方增加内缩 14px 的中性项目栏，圆角上沿与输入框衔接；仅新对话显示，不增加本地模式或 Git 分支。默认「选择项目」，已选中时显示文件夹和项目名，悬停/键盘聚焦显示取消按钮。取消和切换保留当前文字、附件；已有对话不出现目录切换入口。

选择面板向上弹出，宽度最多 320px、限制在视口内，长列表独立滚动。顶部搜索，紧凑列表显示项目名称、弱化的主文件夹名和选中勾号，底部为新建项目与不在项目中工作。搜索支持键盘方向键/Enter，Esc 关闭并返回触发按钮；支持空态、无匹配、加载、服务不可用、错误和重试，沿用浅深主题令牌及既有项目创建 dialog。

## 2026-09-21 对话拖拽补充

项目行仅鼠标悬停时显示背景，选中项目内对话不联动项目背景；对话行保留自身选中背景。键盘焦点使用控件描边，项目行不因焦点停留而持续填充背景。

保持紧凑纯文字行，无额外拖动图标。鼠标/笔按下文字行并移动至少 6px 后进入拖拽，源行淡化，指针旁显示标题；使用发送强调色的 2px 插入线和目标分组描边，不改变列表几何布局。悬停收起项目约 600ms 后展开，拖拽时关闭项目详情浮层。Esc、失焦或目标外释放取消。

支持组内排序、跨项目及移入/移出「最近」；分组标题作为顶部落点。更多菜单提供上移、下移和选择目标分组，保留键盘和触屏可达性。新消息使对话回到所属组顶部，同轮流式输出只触发一次；历史读取不改变手动顺序。存储失败显示明确错误并保留原位置。仅修改列表归类，保留原工作目录。

## 1. 设计目标与取舍

定位：可以长时间使用的桌面 AI 工作工具。视觉关键词是中性、精确、安静、易读。页面的注意力依次落在任务内容、可用操作、运行状态、辅助说明。

- 浅色：浅中性灰侧栏、白色画布、柔和的边界；深色：中性炭灰侧栏与画布、逐级提亮的输入框和弹层。取消大面积冷蓝及蓝色用户气泡。
- 深浅主题共用空间、字体与交互结构，分别定义色彩，禁止整体滤镜反色。
- 通过字重、间距和对齐建立层级；普通对话不套卡片，不用大阴影或大量横线分割内容。
- 不追求压缩每一处留白。导航紧凑，正文舒展；相关信息靠近，无关信息通过段落分开。
- 使用现有能力，不新增没有后端支持的项目、插件、语音、自动化或模型入口。

依据：用户四张现状截图、旧规范、现有 React/Tauri 组件及 ui-ux-pro-max 的 Minimalism & Swiss Style 检索结果。采用其中的中性表面、排版层级和克制交互；自动推荐中的营销落地页结构、青绿/橙色配色、在线字体不适合本项目，不采用。以下数值是本项目设计决策，不是第三方官方令牌。

## 3. 页面结构与构图

### 3.1 应用骨架

- 保留系统原生标题栏及窗口操作；不复制一套窗口按钮。
- 左侧为导航，右侧为完整主画布，二者以细边界分隔。主画布取消左上角特有的大圆角，避免像另一张悬浮卡片。
- 默认侧栏宽 248px，960–1199px 时为 232px；主区宽度随窗口变化。侧栏左右内边距 12px。
- 主区页头高 56px，左右 28px；显示当前标题和必要对话操作，不重复连接成功提示。
- 对话正文与输入框共用最大 760px 的外侧内容轴，桌面安全边距 32px，小窗口 20px。
- 设置正文最大 800px，左右安全边距 40px，顶部 36px。页标题不随分组卡片重复。

### 3.2 对话页面

侧栏顶部为「新对话」和搜索；中部真实对话列表；底部依次为两条连接状态、可用更新入口、设置。对话行 36px，行间 2px；当前项用中性背景与 500 字重标记。无需常驻重命名、归档两个独立小图标，合为可访问的更多操作入口；运行和待确认状态保持独立可见。

正文用户消息靠右，浅灰/深灰气泡；助手正文靠左，无外框。正文以自然段、标题和列表组织。移除每轮过程入口下的通栏装饰横线。单轮内部间距 12–16px；轮与轮间距 28px，不通过固定空白撑高短消息。

历史过程默认收起，在回复邻近位置显示「已完成 · 用时 5 秒」及展开标识；失败、待审批、结果未知不能藏进折叠内容。运行过程在当前轮和输入区显示必要摘要，同一位置不重复放两张状态卡。

输入区是页面最主要的操作面：中性表面、1px 边界、16px 圆角；文字区最小 48px，整体空态约 108px，高度由内容决定。底部工具栏左侧附件，右侧模型/推理选项与发送。输入框上方不新增工作区、设备或分支上下文条。保留独立停止和运行中追加入口。

### 3.3 新对话

页头「新对话」；阅读区域偏上位置显示 28px 欢迎语「今天想完成什么？」及一句简短说明。采用与对话页一致的底部输入位置，进入对话不突然跳动。

可提供最多三个轻量文本起步项，例如「了解一个项目」「整理本机文件」「起草一份文档」。点击只填入可编辑草稿，不自动发送，不暗示原生 Office 解析或图片生成功能。未配置时以配置入口替代起步项。

### 3.4 设置

侧栏切换为「返回应用」与五个现有分类：常规与连接、对话管理、文件与工具、诊断、版本更新。名称保持现有产品语义，不按早期规范恢复四类。

常规与连接的建议顺序：页面标题与一句说明 → 外观 → 连接状态 → 配对/默认输出目录及应用配置。外观即时保存；连接配置仍显式「保存并应用」，两者提示分别归属自己的分组。

普通设置行左右布局：左侧名称与说明，右侧控件；每组一个容器，行间内缩分隔，不给每个字段套卡片。组间 28px，行上下 16px、左右 20px，最小高度 72px。主题可采用三段选择「浅色 / 深色 / 跟随系统」，窄处用带标签的下拉。

连接组保留「中央网关」与「本机设备」两行；设备行解释「本机文件与命令执行」。正常状态在右侧只出现一次。技术名称 Local Agent 可放详情，不能把进程启动当设备在线。

关联用户简明展示；设备完整 ID、网关 URL、CA 和开发覆盖来源放入「连接详情」或「高级设置」。可展开、查看、复制，不删除排障信息。不在普通用户页面放 Spike 等研发术语。

「文件与工具」将默认输出目录与文件/命令能力放在同一语义组，说明它是默认保存位置，不是访问边界。只展示真实配置和能力；已有旧 Agent 兼容提示继续保留。

## 4. 字体与几何令牌

UI 字体：`"Segoe UI", "Microsoft YaHei UI", "Microsoft YaHei", "PingFang SC", system-ui, sans-serif`。使用本机字体，不依赖在线字体。代码：`"Cascadia Code", Consolas, "SFMono-Regular", monospace`。实施时按平台确认中文回退。

| 用途 | 字号 / 行高 | 字重 |
| --- | --- | --- |
| 新对话欢迎语 | 28 / 38px | 600 |
| 设置页面标题 | 24 / 32px | 600 |
| 对话页标题、设置章节 | 15 / 22px | 600 |
| 助手正文 | 15 / 26px | 400 |
| 输入文字 | 15 / 24px | 400 |
| 导航、按钮、设置名称 | 14 / 20px | 400；当前项和名称 500 |
| 次级说明 | 13 / 20px | 400 |
| 耗时、状态、辅助标签 | 12 / 18px | 400 |
| 代码与日志 | 13 / 21px | 400 |

不把关键错误、审批内容或主要输入文字缩到 12px。中文正文不用字距扩张，英文按钮不强制全大写。

- 间距：4 / 8 / 12 / 16 / 20 / 24 / 28 / 32 / 40 / 48px。
- 圆角：普通控件与列表 8px；文件结果 10px；菜单与设置组 12px；弹窗和输入框 16px；发送按钮圆形。
- 图标：统一现有线性 SVG 家族，16px，关键操作 18px，线宽约 1.5px；不使用 emoji 做结构图标。
- 桌面按钮最小高度 32px，主要操作与独立图标按钮 36px；触摸指针有效点击区至少 44px，不挤压相邻操作。
- 浅色输入框仅保留轻微阴影 `0 2px 10px rgba(0,0,0,.035)`；深色无输入框阴影。弹层可用克制阴影，侧栏与普通设置组无阴影。

| `disabled-surface` 禁用底 | `#EAEAEA` | `#393939` |
| `disabled-text` 禁用文字 | `#737373` | `#A3A3A3` |

蓝色限于链接、焦点和真实选中控件，不用于大面积气泡与侧栏。成功状态以小图标和文字表达，不以绿色填满卡片。危险动作仅在对应确认场景使用危险色。

文本在实际表面上至少 4.5:1，关键非文本标记与焦点至少 3:1。装饰边界不代替控件标签和选中标记；必要输入轮廓使用 control-border。正文、次级文字及状态分别核对浅/深主题；不能用整组 opacity 处理禁用态。

主题切换只影响外观，不清空草稿、重连、跳转对话或更改任务。保存原主题偏好，新装默认跟随系统；显式浅色/深色优先于系统。加载前应用已存主题，避免闪白。

## 6. 核心组件与交互

### 文件与附件

文件结果用紧凑横向布局：文件图标、文件名与状态、主要操作。普通文件卡宽度随内容轴，建议最大 520px；单行文件名可省略但须可访问完整名称。第二行显示「已保存到本机」及简短位置，完整路径通过可展开详情/复制获得；不默认输出一整行长路径。

「打开所在目录」保留可见文字，可在窄窗口另起一行。保存中、失败、仅原设备可预览各有独立状态，失败重试保持原语义。文件格式不支持直接打开时不伪造「打开文件」能力。附件缩略图、粘贴、拖拽、删除草稿附件与大图预览继续可达。

### 输入、菜单与审批

- Enter 发送，Shift+Enter 换行；输入法组合期间不发送。发送失败保留草稿，未知提交先核对历史。
- 模型与推理强度保留真实可用数据；菜单向上展开并避让窗口，不被输入区裁剪。
- 运行中停止独立可见，不能因草稿为空而消失；后台对话不抢当前焦点。
- 菜单、弹窗和选择控件支持键盘及 Esc；关闭后焦点返回触发器。弹窗限制焦点在内部，原生语义优先。
- 审批显示动作、目标设备、目录、影响范围及接受/拒绝，异常和审批信息不得为追求简洁折叠掉。
- 危险删除保留现有确认，归档与永久删除不混同；更多菜单含可访问名称和清楚的操作对象。

### 设置与反馈

每个控件有可见标签；帮助文字属于对应字段。配置表单显式保存；切页存在未保存配置时提供保存/放弃/继续编辑，不静默丢弃。成功提示约 3 秒，重要错误持续到处理或关闭。

状态说明靠近问题来源。路径、设备编号和错误允许换行或展开，不通过缩小字号硬塞。异步加载必须能进入成功、错误、取消、超时或可重试状态；不能增加任意短超时把正常长任务误报为失败。

## 7. 状态展示与恢复

| 状态 | 主要展示 | 可用操作/约束 |
| --- | --- | --- |
| 正常连接 | 侧栏两行「中央网关 · 已连接」「本机设备 · 在线」 | 设置查看详情；页头不再重复 |
| 连接中/重连中 | 对应状态行标明文字，必要时输入区短提示 | 保留草稿，沿用真实重连策略 |
| 网关离线 | 网关行 + 输入区离线原因 | 重新连接/连接设置，禁止未知状态提交 |
| 网关在线、设备离线 | 设备行单独报离线，网关仍正常 | 设备诊断，沿用现有操作可用条件 |
| 处理中 | 当前轮阶段、耗时；对应对话状态 | 可追加与停止，不伪造工具执行 |
| 等待本机执行/本机执行中 | 当前任务摘要明确区分 | 展开真实事件/日志 |
| 等待审批 | 当前轮审批面板 + 侧栏待确认 | 接受/拒绝均可达 |
| 已完成/已停止 | 轻量过程入口、真实终态、耗时 | 可展开历史；不把命令完成当整轮完成 |
| 失败/超时 | 就地错误及原因 | 符合现有语义的恢复操作 |
| 提交/执行结果未知 | 持续可见「结果待核对」 | 先核对，不自动重放命令或消息 |
| 加载历史失败/无搜索结果 | 局部错误或空态 | 重试/清除搜索，导航可用 |

连接状态、设备状态、Turn 状态、工具执行阶段是四类独立事实，不以统一绿点相互代替。

## 8. 响应式、可访问性与动效

- ≥1200px：248px 侧栏；960–1199px：232px；720–959px：默认折叠为可打开的侧栏抽屉；更窄维持单列与 16px 边距，不承诺移动产品。
- 主内容不足 560px 时设置控件放到标签下，主题三段可换下拉；模型名称可省略但可聚焦查看，停止与发送始终保留。
- 主画布采用行布局分配页头、可滚动正文、自然高度输入区；不能以固定空白垫高消息区。长草稿、附件、审批不遮住最后一条回复。
- 侧栏列表可滚动，底部状态和设置保留；设置正文独立滚动。窄窗口抽屉关闭后焦点回到开启按钮。
- 100%、125%、150% 缩放分别检查；基准窗口 1042×792（对应现状截图附近尺寸）、1440×900、800×600。
- 焦点环 2px、外扩 2px；所有图标按钮有名称；错误、运行和选中不只靠颜色。装饰图标不重复朗读标签。
- hover/pressed 120–160ms，抽屉/弹层 160–200ms。按钮不移动，流式文本不逐字动画；减少动态效果时取消非必要动画。
