# 中央管理 App：运行概览真实指标

更新日期：2026-09-10。接续[真实链路与登录后界面验收](中央管理App-真实链路与登录后界面验收-2026-09-10.md)，在现有 `spikes/local-dev/apps/central` 接入运行概览的三张统计卡片。最终验收结果见文末。

## 统计口径

| 卡片/字段 | 来源和含义 |
|---|---|
| 在线设备 / `onlineDevices` | 当前网关 Agent 连接中，`ready=true` 且 WebSocket 为 OPEN；仅注册、离线或已撤销设备不计入 |
| 运行任务 / `activeTurns` | WorkerManager 中各用户活动 Turn 槽的总和；包括等待审批、工具或终态确认的活动任务，不是累计 Thread 数 |
| 模型运行进程 / `workers` | 网关登记为 alive、已有有效模型进程 PID 且未进入 stopping 的用户 Worker；不统计宿主电脑其它 Codex/Node 进程 |
| 就绪 / `readyWorkers` | 上述 Worker 中已通过运行初始化的数量 |
| 启动中、停止中 | WorkerManager 中对应状态的数量；可能重叠或尚无进程，不与主进程数构成互斥分区 |

界面只接收总数，不接收用户、设备 ID、进程 PID、工作目录或凭据。模型进程数表示受管 Worker 的运行状态，不是全机进程扫描结果；停止中的 Worker 由单独提示展示。

## 数据通道与状态

网关复用受管进程的 stdout 控制通道 `central-service-host/v1`，在 ready 回执写入完成后立即发送首份 `event:metrics`；其后每次写入完成，再等 2 秒采样，避免 stdout 慢时积累定时请求。正常非受管网关不增加该输出。停止、关闭和失败时停止计时器；非法统计不会用零替代。

原生验证当前服务实例、ready/running 阶段、递增安全整数序号、完整非负计数及边界，使用本机收到帧的时间作为 `observedAt`，通过既有 `central_service_status` 返回 `metrics`。停止、强制退出、失败、已完成清理和新代启动均清空旧指标。未知、非法、旧实例或重复序号的帧不能成为生命周期成功信号。

前端每 2 秒读取原生内存快照，无需管理员登录。超过 10 秒的统计隐藏数字，运行中一直无样本会显示明确错误和重试；原生读取 8 秒超时后结束 loading，仍保留实际请求锁直至 IPC 结束，避免并发重读。隐藏页面暂停轮询，返回前台立即刷新，卸载忽略迟到响应。服务停止且清理已确认显示三个零；失败或清理未确认显示未知，不把未知当零。
