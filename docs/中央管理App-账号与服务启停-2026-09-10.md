# 中央管理 App：账号与服务启停（2026-09-10）

本轮在现有 `spikes/local-dev/apps/central` 中接通 Windows 模型账号和本机验证服务启停。开发版可以使用经过固定清单核验的完整候选包；正式发布资格仍为未完成，Release 构建拒绝候选启动。未修改正式 4510 服务或已安装客户端。

## 已实现

- 模型页和首次配置支持检测本机 Codex 登录、显式导入、账号列表与选择。原生层只从操作系统当前用户目录读取；网页不能指定凭据路径。既有来源允许继承只读权限，拒绝不可信写权限、重解析链接与硬链接。
- 中央账号副本用当前用户 DPAPI 加密，只保留模型代理需要的访问令牌和账号 ID。UI 只收到脱敏提示、时间和状态，不收到原始 token、邮箱或登录 JSON。暂不保存刷新令牌、不自动续期，不把本地有效期检查标为远程可用。
- 运行概览提供首次管理员初始化、启动验证服务、停止、状态刷新和超时结果核对。密码只用于本次请求，不存页面草稿；账号选择只保存不透明 ID。所选账号是该次服务中已启用用户的默认模型来源，切换需重启服务。
- Node、网关、Worker Host、App Server 和 helper 来自原生固定资源包。全部文件和目录在运行期间保持句柄；数据目录有独占锁。只接受新专用目录或当前服务已初始化的私有目录，拒绝自行接管已有数据。
- TLS 私钥、账号和首次管理员密码通过原生 stdin 管道传给网关，不产生中间凭据文件。网关 TLS、账号代理和管理员存储使用既有真实实现。
- 原生后台 actor 管理整个 Windows Job。启动回执要求匹配实例且已监听；正常停止需要停止回执、进程成功退出、输出排空和整个 Job 无活跃进程。强制回收单独显示，清理未确认时不允许新启动。
- 请求意图用 DPAPI 追加记录；同请求重复启动不产生新进程，不同参数复用请求 ID 被拒绝；跨 App 会话旧请求要求核对，不能自动重放。运行期间不允许保存冲突配置。关闭窗口在后台有界停止服务。
