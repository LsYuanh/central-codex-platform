## 维护者配置

以下仅用于人工开发、诊断与验收，不是产品运行依赖。仅设置所选入口需要的变量。示例不能直接用作实际目标；不要把实际值提交仓库。

| 变量 | 含义与约束 |
| --- | --- |
| `CENTRAL_FORMAL_GATEWAY` | 明确选定的正式 WSS 地址；端口 4510、路径 `/ws`，不得含身份、查询参数或片段 |
| `CENTRAL_FORMAL_DIRECTORY` | 远端正式配置/迁移资料的绝对 POSIX 目录；替代历史日期目录默认值 |
| `CENTRAL_QA_HOST` | QA 的 IPv4 地址；相关脚本固定使用隔离端口 4529 |
| `CENTRAL_QA_ROOT` | 远端隔离 QA 资料绝对目录 |
| `CENTRAL_QA_AUTH_FILE` | 需要上游认证的 QA 入口所用远端认证文件绝对路径；只传路径，不打印内容 |
| `CENTRAL_REMOTE_ROOT` | 远端完整项目检出的绝对路径，需包含公共配置 helper |
| `CENTRAL_REMOTE_NODE` | 远端 Node 可执行文件绝对路径 |
| `CENTRAL_SSH_TARGET`、`CENTRAL_SSH_KEY` | 人工运维 SSH 的 `user@host` 和本机私钥绝对路径；不进入客户端产品链路 |
| `CENTRAL_REMOTE_SOURCE_LAYOUT` | 默认根目录布局；仅旧检出使用 `legacy` |
| `CENTRAL_MACOS_DEPLOY_ROOT`、`CENTRAL_MACOS_DEPLOY_NAME` | 既有部署工具根目录与当次部署名称；名称必须显式指定 |
| `CENTRAL_LEGACY_GATEWAY_PID`、`CENTRAL_LEGACY_GATEWAY_CWD` | 旧网关回退工具的 capture 操作必须明确选择进程及含 `dist/index.js` 的目录 |
| `PLAYWRIGHT_MODULE` | 可选，自行安装的 Playwright 模块路径；通常直接使用 npm 依赖 |
| `ATTACHMENT_GATEWAY_URL`、`DEVICE_GATEWAY_URL`、`OUTPUT_GATEWAY_URL` | 对应历史附件、命令和输出探针的显式目标，不再自动连接旧地址 |

远端命令仅转发所需非秘密目标配置。POSIX 路径和 SSH 参数做字符/路径校验，拒绝 shell 注入和越级路径。`harness/build-rc-macos.sh` 使用操作者配置的 Node/Cargo PATH。新配置入口尚未在实际中央机执行部署或生命周期验收。
