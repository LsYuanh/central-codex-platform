## 实现范围

2026-09-03 UI 调整：按用户要求移除手动“本地路径”入口，文件选择改为输入框左下角的加号，保留悬停提示、键盘焦点和可访问名称。修改 `attachments.tsx`、`App.tsx`、`styles.css` 并同步 README；TypeScript check、Vite build 通过，已实际查看 Tauri 页面确认加号位置与旧入口移除。下文原生选择和路径输入的验收描述保留为此前实施记录。

- 在现有 `spikes/local-dev` 中实现图片、文本/代码和普通文件引用；保持中央推理、Agent 客户端执行。
- Tauri 原生多选、拖拽完整路径、本地路径入口、截图粘贴、草稿卡片与本机缩略图。
- 发送前不向中央提交附件路径/内容；发送时复核版本，剪贴板由 Agent 落盘。
- 图片通过 256 KiB 分块进入 App Server 视觉输入；普通文件使用 `device_read_text` 分页读取。
- 平台持久化附件/消息/Turn/来源设备关联；历史恢复保留附件卡片，图片失效可重试本机预览。
- 未知提交状态先核对历史；已成功消息 ID 重复提交返回原 Turn；准备阶段支持取消。
- 自动为旧的 `desktop-device` 默认值分配持久化安装标识，解决实测中另一台设备占用同名 ID 的问题。

限制与参数详见 `spikes/local-dev/README.md` 和 `AGENTRPC.md`。PDF/Office 解析、结构化文件修改属于 P2，未纳入本轮。macOS 代码路径保留，但现场未安装 Rust 工具链，尚未实机编译/运行验收。
