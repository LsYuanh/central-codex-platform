# 模型认证维护手册

维护基线：2026-10-10。中央 0.1.1 起已部署共享登录接入与网关令牌热更新。模型凭据只留中央；客户端不安装 Codex、不保存模型登录、不承担推理。

## 模型连接故障诊断（源码已实现，尚未部署）

`MODEL_PROVIDER_REQUEST_TRANSPORT_FAILED` 表示中央向上游模型服务发请求时发生传输错误，不能据此认定账号过期。旧运行包将网络错误也提示为“检查授权”，此文案不准确。2026-10-10 现场两次请求约五秒后失败，同时另一用户目录获取失败；用户随后反馈重新连接恢复。无凭据连通性探测当时已成功，现有错误码未保留底层原因，因此不能确定是代理、DNS、连接重置还是其他原因，也不能断言重连修复了根因。

新源码在 `model-transport-error.ts` 将请求、流和目录传输错误分为固定后缀 `DNS`、`TIMEOUT`、`CONNECTION_RESET`、`CONNECTION_REFUSED`、`UNREACHABLE`、`TLS`、`CANCELLED`、`MIXED` 或 `UNKNOWN`。只读取白名单系统错误码，有限遍历 cause/AggregateError；不记录原始错误、URL、地址、请求头、令牌或内容。总请求时限单列 `MODEL_REQUEST_TIMEOUT`，用户取消保持取消语义。网络提示要求检查中央网络、代理和上游连通性；授权提示留给凭据/租约错误。旧泛化码仍可解释；不自动重试或重放任务，不放宽 TLS 验证。

本次仅实现、测试和本地提交；中央已恢复，未替换受信运行包、发布或重启。后续正常发布中央运行包后，审计中的细分错误码才会用于现场定位；客户端 0.3.0 本身不包含中央修复。

## 接入方式

| 方式 | 使用和续期 |
| --- | --- |
| 复用本机 Codex 登录（推荐、当前正式使用） | 中央账号库只保存来源、账号 ID、关联时间；官方受管认证进程续期原始登录，再交付最新 access token |
| 中央专用设备登录（可选） | 在浏览器完成设备代码授权，最长等待十五分钟；中央原生凭据库保存独立刷新材料并负责续期 |
| 旧“导入此登录” | 仅复制 access token，不复制共享 refresh token；不会随原登录更新，过期后需显式重新导入或改用关联 |

推荐流程：中央“模型接入”点击“复用本机 Codex 登录”，选中关联账号并启动服务。首次切换账号需停止再启动，此后同账号自动续期不重启网关。原始登录退出、撤销或换账号时，先在中央重新登录，再显式关联；不会静默切换身份。

本版固定读取中央当前系统用户的 `.codex/auth.json`，不接受页面自选路径或任意 `CODEX_HOME`。仅存钥匙串或自定义目录的登录不在此入口范围内。中央 App 及受管服务运行时才续期；Codex 桌面可以关闭。

## 续期与恢复

后台每三十秒检查，通常提前二十四小时刷新；短寿命令牌按剩余寿命一半安排下一次刷新。临时连接失败、限流或指定服务端错误指数退避，初次失败后最多六次重试，间隔从六十秒到最多一千八百秒。失效、身份不符、不确定轮换或重试耗尽显示重新授权，不自动重发模型任务。

共享模式使用核验并锁定的运行包内官方认证二进制，只发送初始化及 `getAuthStatus`；拒绝工具和审批请求。单次限时三十秒，停止服务会取消；关闭 stdin 后最多等两秒，再强制回收。读取落盘结果后重新核对账号、令牌和有效期。中央配置间通过进程互斥与 `.codex/central-auth-owner-v1` 锁串行化，该锁不约束外部 Codex 程序。

独立登录在刷新前持久化 attempt，轮换成功先保存再交付。断电造成结果不确定时要求重新授权，避免盲目复用已轮换 refresh token。Windows 使用当前用户 DPAPI + ACL，macOS 使用 0700/0600 私有权限文件，后者内容未加密。

网关运行包须声明 `accountUpdatesReady`。私有 stdio 控制帧校验实例、账号、递增 revision、到期时间及字段；网关只接收 access token，不接收 refresh token。回执丢失仅允许同 revision/同令牌重试。新请求使用新令牌，已有请求不取消，失败任务不重发。

| 提示或现象 | 处理 |
| --- | --- |
| `MODEL_CREDENTIAL_EXPIRED` | 检查当前选中账号是否旧导入副本；关联中央有效登录并重启切换账号，确认 `/model-access` 为 ready |
| 原始登录缺失、失效或换账号 | 在中央恢复相同账号登录，重新关联；不把别人的账号悄悄接给现有用户 |
| 不支持自动热更新 | 更新完整受信运行包；不能只替换有固定哈希的网关文件 |
| 网络临时失败 | 查看有限退避状态；耗尽后按页面恢复，不无限等待 |
| 中央已恢复、原客户端任务失败 | 重新连接并由用户手动发送，确认此前未知操作结果 |

删除原始登录文件不立即撤销网关内存中的有效令牌；停止使用依赖服务停止、过期或上游撤销。到期时间由上游签发，续期不承诺永久有效。

## 实现与验证

入口位于 `apps/central/src-tauri/src/model_shared_login.rs`、`model_account_renewal.rs`、`model_accounts.rs`；网关热更新在 `services/central-gateway/src/native-service-host.ts`。常规验证和显式认证进程测试见[验证手册](验证与已知限制.md)。

已验证 Windows/macOS 原生认证进程故障、真实中央原始登录读取、正式模型与客户端工具链路、合成令牌热更新。尚未观察真实令牌自然到期后的 refresh token 轮换，独立设备登录也尚未完成真实上游授权及轮换验收。合成成功不代替这些场景。
