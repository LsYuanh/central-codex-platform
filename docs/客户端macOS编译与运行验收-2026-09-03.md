# 客户端 macOS 编译与运行验收

日期：2026-09-03。用户在统一配置完成后要求继续，推进 macOS 原生编译与运行验证。

## 结果与范围

Apple Silicon 原生编译、Rust 检查/测试、配置进程专项、真实中央设备工具和应用正常退出
已通过。发现并修复了 RGB 图标导致 macOS 编译失败、应用退出未回收 Local Agent 两个问题。

本轮借用中央 Mac 同时运行独立测试客户端，仍由该客户端的 Local Agent 执行文件和命令。
这是同机 macOS 兼容性与真实 Broker 验证，不能等同于另一台 Mac 经局域网连接的异机验收。
没有重启现有中央网关，没有新增模型 Turn，也没有重复图片生成。

远程会话 `CGPreflightScreenCaptureAccess()` 返回 false，不能截图检查 Mac 页面。
未修改系统权限；原生页面视觉、目录选择、拖拽/粘贴、红色关闭按钮点击仍待现场复核。
本轮正常退出使用 macOS `NSRunningApplication.terminate()`，不是强杀，也不冒充按钮点击。

## 环境与目录

- 机器：`operator@192.0.2.10`，macOS 26.3.1（25D2128），arm64。
- Node 24.20.0、npm 11.19.0、Rust/Cargo 1.98.0。
- 全局 Xcode 12.3 与当前系统不兼容；现有 Command Line Tools 26.6 / SDK 26.5 可用。
  只在构建进程设置 `DEVELOPER_DIR=/Library/Developer/CommandLineTools`，没有改变全局选择。
- 构建工具位于 `/Users/operator/central-codex-platform/artifacts/macos-tools/`，未修改用户 shell 配置。
- 当前源码复制至同一仓库路径 `/Users/operator/central-codex-platform/spikes/local-dev/`。
  原部署网关 `/Users/operator/central-codex-platform/services/test-gateway/` 保持运行。
- 原生二进制位于 `spikes/local-dev/target/debug/desktop-spike` 和 `local-agent`，均为
  `Mach-O 64-bit executable arm64`；桌面经 Tauri CLI 构建并内嵌前端，运行时无需 Vite。

前置条件参考 [Tauri 官方说明](https://v2.tauri.app/start/prerequisites/)；
按进程指定开发工具目录参考 [Apple 文档](https://developer.apple.com/documentation/xcode/configuring-command-line-tools-settings)。
