## 完成的实现

沿用 `spikes/local-dev/apps/central`，没有新增另一套产品入口。

- Mac 配置保存与账号/证书导入；私有目录 0700、私有文件 0600，逐级拒绝符号链接，记录操作相对已打开目录执行，运行数据目录有独占锁。这是 POSIX 权限保护，不是 Keychain 或加密存储。
- 固定读取中央 Mac 当前系统用户的 `.codex/auth.json`，只保留模型代理所需的 access token/account ID，不读取客户端登录、不把推理放回 Windows 客户端、不执行账号刷新或撤销。
- DER 证书有效期、CA 和 keyCertSign 检查，链、域名、用途及私钥匹配仍由 Rustls 验证。
- Mac 服务守护进程管理独立进程组；控制端异常退出后也清理网关及其后代，只有整个进程组退出才确认清理完成。
- 内置 Node 24、已修补 App Server、网关依赖与 Seatbelt profile；独立清单锚定全部文件。Mac 默认 256 个文件描述符不足以同时固定完整包，原生层按内置包规模在硬上限内提高本进程软限制。
- 网关支持 Mac 原生 bootstrap、TLS、管理员和内存模型凭据代理，Worker 继续通过 Seatbelt 隔离；实际客户端文件和命令仍由 Local Agent 执行。
- Mac `.app` 与 DMG 打包。内嵌 Mach-O 在生成资源哈希前签名，最终 App 再核验资源；DMG 由 `hdiutil` 生成并验证，避免无显示器环境的 Finder AppleScript 依赖。

## 开发复现

原生构建使用现有 Node 24、Rust 工具缓存与 `/Library/Developer/CommandLineTools`，不修改系统全局 Xcode 选择。

```sh
sh scripts/build-central-macos-on-host.sh /absolute/patched/codex-app-server
```

该入口调用 `scripts/package-central-macos.mjs`；依赖需事先按 `package-lock.json` 安装。`macos-formal-prepare.mjs`、`macos-formal-switch.mjs`、`macos-formal-management.mjs`、`macos-formal-restart.mjs` 是本次明确授权的开发部署/验收工具，SSH 只负责开发部署与诊断，不进入产品运行链路。`central-formal-client-smoke.mjs` 在 Windows 以真实用户权限运行，其配对码仅经管道传给原生客户端。
