## 评审重点

- 浅色侧栏与白色主区是否协调；深色表面是否层次清楚、适合长时间阅读。
- 侧栏宽度、主内容留白、正文和输入区的比例是否合适。
- 文件结果是否足够紧凑，文件名、保存结果与打开所在目录操作是否易找。
- 设置是否能先看到主题、连接与保存位置，技术细节是否适合收起。
- 运行中停止与追加是否都可见；断线和结果未知能否正确引导恢复。
