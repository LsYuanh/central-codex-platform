## 当前设计

- `platform-auth.ts` 在现有网关增加 HTTPS 身份 API 和 WSS 身份校验；仅在 `PLATFORM_AUTH_FILE` 配置下开启，必须提供 TLS 证书/密钥，测试控制入口全部关闭。
- 管理员本地首次引导账号；后续账号经管理员 API 创建。密码使用 Node scrypt（N=131072,r=8,p=1），异步计算并限制并发/登录速率。
- 平台身份由不透明访问令牌确定（5 分钟），刷新令牌轮换、复用撤销整个会话，最长 30 天；磁盘仅保存摘要。
- 登录后一次性、两分钟有效且绑定用户/会话的配对授权，设备生成 Ed25519 密钥；服务端只保留公钥和摘要。
- Agent 经 HTTPS 获取 30 秒一次性挑战，签名后交换 15 秒一次性 WSS 凭据。该层为 TLS 上的设备签名认证，尚非客户端 X.509/mTLS 证书体系。
- 现有 Tauri 设置页加入账号、配对、吊销和 CA 路径设置。Rust 原生层保存登录/设备密钥到 Windows Credential Manager 或 macOS Keychain；没有文件降级。页面不会取得访问/刷新令牌或设备私钥。
- WSS 使用原生 Channel 适配现有协议客户端，检查 CA、证书期限及主机名；可按中央地址添加私有 CA，不修改系统根证书库、不关闭证书校验。
- 注销、用户停用和设备吊销使现有连接失效；Agent 的已有断线取消机制清理实际客户端命令。
