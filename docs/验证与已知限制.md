## 显式原生与真实链路检查

桌面生命周期专项先构建 Agent，在独立 shell 设置 `CODEXIA_LOCAL_AGENT_PATH` 指向构建文件，再运行：

```powershell
cargo test -p desktop-spike runtime_process_integration -- --ignored --nocapture
```

测试 shell 不应带其他网关/目录覆盖。真实生命周期按本机 App 和 Agent 同时出现/退出、中央对应设备上线/下线验收；多设备环境看增减和目标设备，不要求全局 devices 归零。

中央认证进程专项指定 `CENTRAL_SERVICE_QA_NODE` 后运行：

```powershell
cargo test -p central-app --bin central-app owned_authentication_process_protocol_timeout_cancel_and_cleanup_qa -- --ignored
```

真实原始登录检查另需 `CENTRAL_SHARED_AUTH_QA_RESOURCES`、`CENTRAL_SHARED_AUTH_QA_PACKAGE`，运行 `existing_central_login_authentication_qa -- --ignored`，只在授权的中央用户上下文执行。

当前正式模型与 Windows 安装 Agent 的验收入口：

```powershell
node scripts/central-formal-client-smoke.mjs --bundle --installed
```

该脚本使用临时设备，验证配对持久化、两次客户端读取、一次客户端命令、默认目录外访问和历史恢复，最后撤销测试设备、退出测试 Agent、归档测试对话。旧 Agent 兼容专项使用 `--bundle --legacy`，需存在对应旧版测试二进制。不能把 Windows 同机中央测试当作 Mac 或跨机矩阵通过。
