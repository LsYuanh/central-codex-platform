## 页面变化

图片卡片按钮后续调整：查看大图、打开所在目录、重新读取和重试保存统一使用 32px 最小高度、细边框与中性底色，显式覆盖悬停/按下/禁用状态，避免继承全局主按钮悬停色造成文字对比不足；图片缩略图悬停也使用中性色。继续使用双主题语义颜色，保留键盘焦点提示。

默认外观后续调整：首次使用或没有有效主题记录时，首屏初始化与应用状态均默认浅色；已保存的浅色、深色和跟随系统选择继续保留。

原生标题栏后续修复（2026-09-07）：`theme.ts` 在启动恢复及主题切换时同步调用 Tauri `getCurrentWindow().setTheme`；浅色/深色显式设置，跟随系统传 `null` 清除覆盖。`src-tauri/capabilities/default.json` 为主窗口增加 `core:window:allow-set-theme`，浏览器预览不调用原生 API。前端 check/build、`cargo fmt --check`、`cargo check -p desktop-spike` 通过；实际 Windows Tauri 窗口已确认深色、浅色与当前系统浅色模式下标题栏和页面一致。未修改 Windows 系统主题来测试外部切换，也未重验 macOS；安装包未重建。

主题选择后续调整：使用 `ThemePicker.tsx` 自定义菜单替代系统原生 select，统一双主题圆角、图标、选中勾和悬停样式。鼠标点击不显示额外蓝色外框；键盘保留焦点提示、方向键/Home/End 选择、Enter/Space 确认及 Escape/Tab 关闭。菜单挂载到页面顶层并按视口定位，避免被设置分组裁切。双主题、窄窗口、外部点击、焦点恢复和系统主题切换的浏览器交互验证通过，前端 check/build 通过。

- 统一浅色、深色语义颜色、字体、间距、圆角与细线图标。浅色采用灰蓝侧栏和白色画布，深色采用冷灰侧栏、炭灰画布与较亮输入框，主操作为黑白按钮。
- 重构侧栏、首页、对话消息、输入框、执行反馈、附件/输出卡片、设置分组与本机文件区的样式。
- 输入框上方不显示项目/设备上下文条，也不保留占位。网关与设备状态分别显示在侧栏底部。
- 正文和输入框共用 760px 内容轴；按用户追加要求将侧栏加宽 40px，宽屏 300px、960–1199px 使用 272px，更窄窗口采用最多 300px 的可关闭导航抽屉，至少保留 32px 遮罩区域。加宽后前端 check/build 通过。
- 首页提供四个任务建议，只填入草稿；支持多行输入自适应高度、回到最新消息、菜单 Escape 关闭与窄屏导航焦点恢复。
- 外观支持浅色、深色、跟随系统；保留旧主题偏好，启动时先应用主题，并监听系统主题变化。
