# 中央管理 App：运行资源与证书接入

本轮继续用户已确认的中央端开发，在现有 `spikes/local-dev/apps/central` 接入运行包清单、文件核验和 Windows 服务器证书导入。中央服务启停仍禁用；正式 Windows Worker、完整网关运行包和模型账号管理尚未接通。

## 实现

- 首次配置第三步从内置清单选择候选运行包，按原生应用资源目录逐项检查大小与 SHA-256。清单编译进程序，外部 manifest 不能替换信任根。当前候选只有已验收 App Server 和 LICENSE/NOTICE，始终 `qualified=false`、`ready=false`。
- 原生目录选择器读取 `server.pem`、`server-key.pem`、`ca.pem`。私钥要求未加密 PKCS#8 PEM。校验证书链、CA 约束与签发用途、服务器用途、证书有效期、当前客户端 URL 主机名/IP，以及私钥匹配。
- 验证通过后，用当前 Windows 用户 DPAPI 加密整个证书包，写入 AppData 的 `central-secrets/tls-certificates-v1/<随机ID>.dpapi`。只新增、不覆盖；目录 ACL 受保护，拒绝重解析点、硬链接和不安全路径。普通配置仅保存证书 ID，renderer 仅收到公开元数据。
- 证书列表每次按当前地址和时间重新验证，单个坏记录显示失败。启动前检查按已保存配置重读证书；公共 CA 导出不含私钥且不覆盖已有文件。
- 导入、导出、刷新及哈希检查有进行中、取消、成功、失败和超时状态；超时提示刷新核对。原生选择窗口互斥，配置保存不在资源操作进行时提交。

秘密存储信任当前用户和管理员；不把它描述为抵御同用户恶意进程的完整隔离。未安装操作系统信任、未开放端口、未做在线 CRL/OCSP 吊销检查。合成测试密钥明确标注，仅用于测试。

## 候选资源准备

在 `spikes/local-dev` 运行，源根必须显式指定为包含已记录构建和许可证的仓库。哈希不同会拒绝暂存，不能任意选一个本机 Codex 替代。

```powershell
node scripts/stage-central-runtime.mjs --source-root C:\Workplace\central-codex-platform --package-id windows-x64-codex-0.153.4-qa1
npm run tauri:build --workspace @central-codex-spike/central -- --debug --config C:\Workplace\central-codex-platform\spikes\local-dev\apps\central\src-tauri\tauri.runtime-qa.conf.json
```

暂存目录为 `spikes/local-dev/target/central-runtime`，约 249 MB，不提交 Git。可选 Tauri 配置将其映射到 `resource_dir/central-runtime`。普通构建不要求该候选目录存在，资源缺失会显示真实缺失状态。本轮未生成或发布正式安装包。

## 验证与后续

验证结果见同轮 `harness/verification/central-resource-qa-2026-09-10.json`。原生 ACL/DPAPI 测试须在真实 Windows 用户权限下运行；受限执行环境会拒绝目录检查，不能据此放宽产品权限。

- `cargo test -p central-app -p platform-security --offline -- --test-threads=1`：中央端 28 项、安全模块 25 项通过；合成 UI QA 准备测试默认 ignored，并已单独执行通过。
- TypeScript check、Vite build、`cargo check -p central-app --offline`、限定 crate 的 fmt check、两项前端配置 smoke 通过。
- Windows 原生 QA 已恢复版本 1 配置、合成证书指纹及有效期；证书检查通过，目录与隔离仍显示未检查。
- 最终真实页面显示候选包文件哈希通过、系统/端口/证书通过，完整运行包仍需处理。Debug 下约 249 MB 的核验在 34 秒内观察到完成；UI 检查上限改为 60 秒，原生文件核验互斥，避免超时重试叠加工作。
- 修复真实桌面验收发现的两种路径情况：MSIX 启动上下文会将逻辑 AppData 映射到包缓存，先固定逻辑目录排除链接，再规范化到物理路径供秘密存储重新逐层检查；Windows verbatim 前缀 `\\?\C:` 尚不是根目录，资源核验须到 RootDir 后才读元数据。

合成 QA 使用 `com.yuanzhou.central.resource-qa-20260910` 独立标识，未改变正常应用配置。当前合成服务器证书于 2026-09-30 到期，之后不能沿用它做真实时钟的 UI QA；常规回归通过仅测试编译的线程局部时钟固定日期，生产始终使用系统时间。
