## 实现

- 中央私有 CA 独立于服务端 TLS 和模型凭据，限制文件所有者、权限、单链接和 Worker 路径。
- 客户端本机生成 RSA-2048 密钥；独立二进制系统凭据库记录保存私钥和证书，避免 Windows 单条大小限制以及会话刷新并发写入。
- 配对公钥与既有 Ed25519 设备身份、平台用户绑定；Agent WSS 同时验证签名票据和 mTLS。
- Agent 自动通过 mTLS 续期；原连接的相同设备/会话获得新的授权期限，正在执行的命令无需为续期重启。
- 吊销关闭全部对应设备连接。证书过期而未续期时连接到期关闭，客户端命令取消；恢复需显式重新配对。
- 设置页显示有效期、续期中、暂时失败和重新配对状态，不把证书错误无限隐藏在重连中。

CA 默认证书策略为 7 天有效、提前 1 天续期；第四批中央 QA 将使用 120 秒有效、提前 60 秒续期。
CA 本身 1 年有效；本批没有实现 CA 信任链自动轮换、安装包发布或正式迁移。

## 安全与兼容边界

HTTPS 共用一个监听端口：登录、配对和 UI 使用服务端 TLS，Agent 接入和设备续期要求客户端证书。
因此无证书的 HTTPS 握手本身可以成功；Agent 路由仍拒绝无证、异 CA、外来设备或重用 TLS 会话。
对长连接的续期是通过已验证 mTLS 的应用层重新授权，不宣称替换已有 TLS 握手。

旧设备记录可读取，但不能无证书接入新版真实网关；需要显式重新配对。旧 Thread 的设备绑定不会被迁移绕过。
Windows 原生 TLS 私钥导入存在持久 CryptoAPI 容器副作用，客户端身份链路改用内存中的 Rust TLS；
系统凭据库仍是唯一应用管理的持久私钥存储。
